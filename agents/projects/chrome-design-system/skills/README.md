# Skills: Chrome Design System

This directory contains all of the agent skills used by the Chrome Design System.

## Installing skills

We recommend installing these skills at the workspace level using symlinks so that your model always has the latest version. Here is a prompt that works for Gemini:

> There are several agent skills in `agents/projects/chrome-design-system/skills/`. Create symlinks in `.agents/skills/` to each skill's folder.

This is a sample Cargo package to test `gnrt`'s dependency resolution. The
output of `cargo metadata` is recorded and used as test data.

`tools/crates/gnrt/lib/test_metadata5.json` is generated by the output of
running `cargo metadata --format-version 1 --offline` in this directory.

This directory checks that `gnrt` simulates version 2 of Cargo's feature
resolver: the `target_only` feature of `shared` is enabled for the normal
dependency, but not for the `build.rs` dependency.
